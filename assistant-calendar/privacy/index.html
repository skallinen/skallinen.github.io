Assistant calendar privacy policy

Version 1, 2 November 2026.

Who uses it

Assistant calendar is a personal tool. Its only user is its author, Sami Kallinen, who signs in with his own Google accounts.

What it reads and writes

With the access granted on Google's consent screen, it reads the events in the author's own calendars. In each calendar it writes only "Busy" blocks that mirror busy time from his other calendars, carrying no titles, places or attendees from the original events.

Where the data goes

Calendar data is processed and kept on the author's own home server. It is not sold, shared, sent to third parties or used for advertising, and it is not used to train any model.

Keeping and deleting

Access can be withdrawn at any time in the Google account under Security, Third-party apps. The author can delete the stored copies on his server and the Busy blocks in his calendars.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
